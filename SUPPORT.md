# Support

Before requesting help, review the project documentation and search existing reports for the same problem.

Use the project's issue tracker or other documented support channels to request help.

Remove secrets, credentials, and personal data from examples and logs.

Include the project revision, operating system/browser, emulator system and a
minimal reproduction. Use original synthetic files when possible. Do not attach
ROMs, BIOS, system images or private saves, even if they would make reproduction
easier. A game title and hash can identify a compatibility case without distributing
the game itself. Installation and recovery instructions are in
[deployment](platform/DEPLOYMENT.md) and storage operations.

Report suspected security vulnerabilities privately according to [SECURITY.md](SECURITY.md).
